# 👜 Scatch – Premium Bag Shop  

A **full-stack e-commerce web application** for premium bags, built with **Node.js, Express.js, MongoDB, and EJS**.  
This project demonstrates **authentication, authorization, product management, and cart functionality** in a real-world shopping scenario.  


## 🚀 Features  

### 👤 Authentication & Authorization  
- Secure **JWT-based login system**.  
- Role-based access: **Admin** vs **User**.  

### 🛍️ Admin Features  
- Add, update, and delete bag products.  
- Manage products directly from admin dashboard.  

### 👥 User Features  
- Browse products on the **Shop page**.  
- Add selected items to the **cart**.    

### 🗄️ Data Handling  
- MongoDB database for **users, products, and carts**.  
- Flash messages for better user experience.  

### 🎨 Frontend (EJS Templates)  
- Dynamic rendering of shop, cart, and admin pages.  
- Simple and clean UI.  


## 🏗️ Tech Stack  

- **Frontend**: EJS (Embedded JavaScript templates)  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Authentication**: JWT (JSON Web Tokens)  
- **Password Security**: bcrypt for password hashing  
- **Styling**: TailwindCSS
